# CLAUDE.md — сайт Party Game Нячанг

Статический SEO/GEO-сайт клуба социальных игр в Нячанге. Домен: https://partygame-nhatrang.com. Подробности по структуре и настройкам — в `README.md`, факты о клубе — в `src/data/site.ts`.

Соседний проект: `partygame-nhatrang-app` (Telegram Mini App и бот для записи на игры, Next.js + Prisma + Supabase + Vercel). Это отдельный репозиторий со своим `CLAUDE.md`.

## Бренд и язык

- Бренд: **«Party Game Нячанг»** (латиницей — Party Game Nha Trang, PARTY GAME community).
- Язык сайта: **только русский**. Других языковых версий нет, `hreflang` не нужен.
- Тон: живой, без канцелярита и «ИИ-стиля». Для новых текстов подходит скилл `zhivoy-russkiy-tekst`.
- Площадка: CCCP Coffee, 112 Đ. Hồng Bàng, центр Нячанга. Игры 19:00–23:00.
- Цены: Авалон — от 150 000 ₫, мафия и «Кровь на часовой башне» — 200 000 ₫. Лила (коучинговая игра) — в долларах, см. `lila` в `site.ts`.

## Стек

- Astro 5 (статика), `@astrojs/sitemap`, шрифты через `@fontsource`.
- Node 22 (`.nvmrc`). Локально работает и на более новой версии.
- Хостинг: Cloudflare Pages, проект `partygame-nhatrang`, сборка `npm run build`, папка `dist`.

## Структура

- `src/data/` — `site.ts` (факты), `schema.ts` (Schema.org), `faq.ts`, `reviews.ts`.
- `src/pages/` — страницы; `llms.txt.ts` и `robots.txt.ts` генерируются кодом.
- `src/content/blog/` — статьи в `.md`, имя файла = URL.
- `src/components/` — блоки страниц; `src/assets/` — фото, которые Astro сжимает; `public/` — файлы как есть.

## Как вносить правки и деплоить

1. `git pull`, прочитать `src/data/site.ts`.
2. Правки в коде или тексте.
3. `npm ci` (если менялись зависимости) и `npm run build`: сборка должна пройти без ошибок.
4. Коммит в `main` и `git push origin main`. Cloudflare Pages сам соберёт и опубликует сайт за 1–2 минуты. Ручная загрузка архивов не нужна.
5. Проверить изменённые страницы на https://partygame-nhatrang.com.

Ветка `main` = продакшн. Для крупных или рискованных изменений лучше отдельная ветка и PR. Токены и пароли не писать в файлы, коммиты и чат.

Новая статья: скопировать любой файл из `src/content/blog`, поменять имя файла, заголовок, описание, дату и текст.
